Linear Algebra

Build intuition before the algebra

Linear algebra tells us how vectors, planes, and higher-dimensional data respond to matrix operations. These notes pair clean explanations with the interactive Matrix Multiplication playground so you can see each concept morph the grid in real time.

The goal is to treat a matrix as a machine: drop a vector in, and a new vector comes out. The animations show how rows remix coordinates and how columns drag the axes to new positions without needing heavy algebra.

How the matrix animation works

The playground repeats the same story every time you choose a new matrix. Follow the steps below while you watch the grid morph.

  1. Highlight a row. The animation pulses one row at a time so you can see how those numbers mix the input coordinates to produce a single output value.
  2. Trace the columns. The bright handles on the grid are just the transformed versions of the standard axes. Dragging them helps you predict the final orientation.
  3. Watch the green square. Its area tells you how much the transformation scales space, and whether the orientation flips. If the square collapses, the transformation squashes a dimension.
  4. Compare with coordinates. As the point moves, the numeric readout updates so you can verify that the formulas match the visual motion.

Behind the animation

The visuals are driven by three simple formulas that run every frame:

  1. Row mixing. Each highlighted row computes one output value using the dot product yi = ai1x1 + ai2x2 + … + ainxn. That is why the corresponding axis number changes as soon as the row glows.
  2. Column remapping. The axis handles come from the column combination Ax = x1a1 + x2a2 + … + xnan. Sliding a column instantly shows how the entire plane is built from those vectors.
  3. Area tracker. The green square scales by the determinant, so in 2D it multiplies its area by (ad - bc) when A = [[a, b], [c, d]]. A zero determinant collapses the square, explaining why some transformations cannot be inverted.

Key ideas at a glance

The notes focus on interpreting matrices as transformations. Every derivation starts with a picture so the symbolic manipulations make geometric sense.

Rows as dot-product filters
Each row selects a weighted mix of the input coordinates. Watching the row glow inside the animation makes it obvious that one line of numbers controls exactly one number in the answer.
Columns as new basis vectors
The columns show where the unit vectors land. When you drag the columns in the grid, you literally see how the axes bend, which explains rank, determinant, and shear ideas with a single motion.
Determinant as area scale
Track the green parallelogram to see how orientation flips and area scaling emerge straight from the numbers. Positive determinants keep the orientation, negative ones flip it, and the size tells you exactly how much the grid stretches.

Example walkthrough

Pick the matrix [[2, 1], [1, 3]] inside the playground. The first row mixes two copies of the x-value with one copy of the y-value, so a point like (4, -2) turns into 6 on the x-axis. The second row leans heavily on the y-value, which is why the new y-coordinate drops to -2 even though the original point had a positive 4.

Input: (4, -2)
Output: (6, -2)
Observation: the grid stretches about five times larger, so areas grow by that factor.

This tiny story shows how to read every animation: rows describe how much you blend coordinates, columns reveal where the axes land, and the green square reports how much the transformation scales shapes.

Guided questions

Use these step-by-step prompts while exploring the animations. Each one walks through the reasoning so newcomers can follow along without extra background.

1. What does the matrix [[0, 1], [-1, 0]] do to any point?

This is the classic rotation puzzle. Follow the steps to see why it always spins the plane 90° counterclockwise.

  1. Check what happens to the x-axis: plug in (1, 0) and the output becomes (0, -1), which lives on the negative y-axis.
  2. Check the y-axis: plug in (0, 1) and the output becomes (1, 0), which lands on the positive x-axis.
  3. Because the matrix only repositions the axes, every other point follows the same quarter-turn sweep in the animation.

2. How can I tell if a matrix is invertible just by looking at the grid?

Invertible means you can reverse the transformation. The visual test is quick:

  1. Watch the grid while you drag points. If the green parallelogram collapses into a line, information is lost and the matrix is not invertible.
  2. If the shape stays 2D and never folds the entire square onto a line, there is always a way back.
  3. The animation labels also show the determinant. Any determinant other than zero matches the “still a full shape” observation.

3. Why do columns reveal the rank of a matrix?

Rank counts how many directions survive the transformation. Follow the columns to see it play out.

  1. Drag the column handles. If one column lies on top of the other, both axes land on the same line, meaning only one direction remains — rank 1.
  2. If the columns stay separated, you still have two independent directions, so the matrix has rank 2.
  3. This geometric picture matches the algebraic definition but feels tangible because you can see the axes collapsing or staying apart.
