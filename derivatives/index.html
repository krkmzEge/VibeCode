    Derivatives

    In calculus, the derivative is a measure of how a function changes as its input changes.

    Power Rule

    The power rule is used to differentiate functions of the form \(f(x) = x^n\).

    \[ \frac{d}{dx}x^n = nx^{n-1} \]

    Example:

    For \(f(x) = x^3\), the derivative is \(f'(x) = 3x^2\).

    Product Rule

    The product rule is used to differentiate the product of two functions.

    \[ \frac{d}{dx}(u \cdot v) = u \frac{dv}{dx} + v \frac{du}{dx} \]

    Example:

    For \(f(x) = x^2 \sin(x)\), let \(u = x^2\) and \(v = \sin(x)\). Then \(f'(x) = x^2 \cos(x) + 2x \sin(x)\).

    Quotient Rule

    The quotient rule is used to differentiate the quotient of two functions.

    \[ \frac{d}{dx}\left(\frac{u}{v}\right) = \frac{v \frac{du}{dx} - u \frac{dv}{dx}}{v^2} \]

    Example:

    For \(f(x) = \frac{\sin(x)}{x}\), let \(u = \sin(x)\) and \(v = x\). Then \(f'(x) = \frac{x \cos(x) - \sin(x)}{x^2}\).

    Chain Rule

    The chain rule is used to differentiate composite functions.

    \[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} \]

    Example:

    For \(f(x) = (x^2 + 1)^3\), let \(u = x^2 + 1\) and \(y = u^3\). Then \(\frac{dy}{du} = 3u^2\) and \(\frac{du}{dx} = 2x\). So, \(f'(x) = 3(x^2+1)^2 \cdot 2x = 6x(x^2+1)^2\).

    Advanced Examples

    Here are some more complex examples that combine the rules above.

    1. Combining Product and Chain Rules

    Let's find the derivative of \(f(x) = e^{x^2} \sin(3x)\).

    This requires the Product Rule (\(u = e^{x^2}\), \(v = \sin(3x)\)) and the Chain Rule for each part.

    • For \(u = e^{x^2}\), the derivative is \(u' = e^{x^2} \cdot 2x\).
    • For \(v = \sin(3x)\), the derivative is \(v' = \cos(3x) \cdot 3\).

    Applying the product rule \(f'(x) = uv' + vu'\):

    \[ f'(x) = (e^{x^2})(3\cos(3x)) + (\sin(3x))(2xe^{x^2}) \]

    Factoring out \(e^{x^2}\):

    \[ f'(x) = e^{x^2} (3\cos(3x) + 2x\sin(3x)) \]

    2. Implicit Differentiation

    Consider the equation of a circle: \(x^2 + y^2 = 25\). We can find the slope of the tangent line, \(\frac{dy}{dx}\), without solving for \(y\).

    Differentiate both sides with respect to \(x\):

    \[ \frac{d}{dx}(x^2) + \frac{d}{dx}(y^2) = \frac{d}{dx}(25) \]

    Using the chain rule for \(\frac{d}{dx}(y^2)\):

    \[ 2x + 2y \frac{dy}{dx} = 0 \]

    Now, solve for \(\frac{dy}{dx}\):

    \[ 2y \frac{dy}{dx} = -2x \]
    \[ \frac{dy}{dx} = -\frac{x}{y} \]

    3. Logarithmic Differentiation

    Let's find the derivative of \(f(x) = x^x\).

    This is tricky because the variable appears in both the base and the exponent. We can use logarithms to simplify it.

    Let \(y = x^x\). Take the natural logarithm of both sides:

    \[ \ln(y) = \ln(x^x) \]

    Using logarithm properties, we get:

    \[ \ln(y) = x \ln(x) \]

    Now, use implicit differentiation (differentiate both sides with respect to \(x\)):

    \[ \frac{1}{y}\frac{dy}{dx} = (1)(\ln(x)) + (x)\left(\frac{1}{x}\right) \]
    \[ \frac{1}{y}\frac{dy}{dx} = \ln(x) + 1 \]

    Solve for \(\frac{dy}{dx}\) and substitute \(y = x^x\) back in:

    \[ \frac{dy}{dx} = y (\ln(x) + 1) = x^x (\ln(x) + 1) \]
